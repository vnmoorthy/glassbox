The problem

Agents can already click “Buy.”
Nobody lets them.

?Why did it pick that one, and what did it ignore?
⚖Did it follow my rules: budget, size, brands I hate?
🔒Can I prove what happened, or could the log be edited?

Today’s agents answer with a chat bubble: “Done! ✅” That’s not good enough for money.

Glassbox02 / 10
The insight

Trust = evidence + rules + proof.

So we built the agent as a glass box. Every step is an event, every event cites its evidence, and every event is hash-chained to the one before it.

Reliable context

It knows you. It doesn’t fall for tricks.

🧠 Memory it actually uses
  • You wear glasses → requires low-clamp pads
  • You returned narrow Kestrels → skips Kestrel
  • You like eco → small bonus, shown
  • Never-buy brands → hard reject
🛡 Manipulation it catches
  • 4.8★ with 46% fake reviews → rejected
  • $199 bait from flagged seller → ignored
  • Price 12% above 30-day avg → flagged
  • Can’t ship by deadline → excluded
Adjusted rating = Bayesian over genuine reviews only
